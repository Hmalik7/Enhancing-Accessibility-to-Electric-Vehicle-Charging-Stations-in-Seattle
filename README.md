# ⚡ Enhancing Accessibility to Electric Vehicle Charging Stations in Seattle

## 📝 Overview
Welcome to the repository for **"Enhancing Accessibility to Electric Vehicle Charging Stations in Seattle, Washington"**, authored by **Max Davis** and **Harsh Malik**. This proposal analyzes the current EV infrastructure in Seattle and recommends strategic locations for new charging stations in underserved areas, ensuring equitable access and a sustainable future.

## 📂 Contents
- 📄 **EV_Project.pdf**: The core document detailing the proposal, including:
  - Executive Summary
  - Methodology
  - Findings and Recommendations
  - Maps illustrating coverage gaps and priority areas

## 🌍 Key Points
- 📉 **Equity in Accessibility**: Highlights disparities in EV charging infrastructure across Seattle, with a focus on low-income neighborhoods.
- 📊 **Data-Driven Insights**: Combines income, traffic volume, and network analysis to propose targeted solutions.
- 🌱 **Environmental Justice**: Advocates for clean transportation and sustainable practices.

## 🚀 How to Use
This repository is designed for sharing the proposal and engaging with stakeholders to address the gaps in EV accessibility in Seattle. Contributors and reviewers are encouraged to:
1. Open **Issues** for feedback and discussions.
2. Use the insights and recommendations to inform planning and policies.
